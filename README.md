# ApiEcommerce


REST API desarrollada en **ASP.NET Core** para un sistema de e-commerce.
El proyecto implementa un stack backend completo.

## Objetivo del proyecto
Diseñar una API escalable y mantenible, enfocada en separación de responsabilidades,
modelado de dominio y persistencia de datos eficiente.

## Tecnologías
- C#
- ASP.NET Core
- Entity Framework Core
- SQL Server
- Swagger / OpenAPI

## Arquitectura
- Controllers (API Layer)
- Domain Models
- DTOs & Mappers
- Repositories
- DbContext con EF Core

## Features implementadas
- CRUD de Products
- CRUD de Categories
- Login y Creacion de usuario
- Mapeo DTO ↔ Entidades
- Persistencia con EF Core
